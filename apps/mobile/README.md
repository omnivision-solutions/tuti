# Tuti for iOS and Android

The Inbox on a phone (`docs/plan.md`, "Mobile app"). React Native with Expo; routes live in `src/app`.

```sh
pnpm --filter @tuti/mobile start    # the dev server; open it in a development build
pnpm --filter @tuti/mobile bundle   # bundle for both platforms, as a build would
```

`ios/` and `android/` are generated by Expo and never committed: native settings go in `app.config.ts`.
A build belongs to the Expo account and project in `EXPO_OWNER` and `EAS_PROJECT_ID`, and uses the app id
in `APP_ID`, so a fork builds its own app without changing this directory.
