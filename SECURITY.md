# Security

Please don't report security issues in public issues or pull requests.

Report them privately through GitHub: **Security → Report a vulnerability** on this
repository. Include what you found, how to reproduce it, and what an attacker could do
with it. We'll reply within a few days and keep you posted until it's fixed.

Only the latest code on `main` gets security fixes.

Especially welcome: ways to act as another user or in another project (sessions, JWT SSO,
team roles, server actions), and ways around portal isolation between projects.
